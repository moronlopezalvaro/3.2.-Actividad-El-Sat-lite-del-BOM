# 3.2. Actividad: El Satélite del BOM

Práctica de Desarrollo Web en Entorno Cliente (2º DAW). Muestra la interacción entre ventanas usando objetos del BOM: `window`, `screen`, `navigator` y `location`.

- [index.html](index.html): ventana principal. Lanza la ventana satélite centrada en la pantalla.
- [satelite.html](satelite.html): detecta el sistema operativo, controla la navegación de la ventana principal (`assign` / `replace`) y se autodestruye a los 5 segundos.
- [analisis.md](analisis.md): respuestas teóricas (criterio a).

**Demo:** https://moronlopezalvaro.github.io/3.2.-Actividad-El-Sat-lite-del-BOM/
